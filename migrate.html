NTPU PF OB Stats migration tool

One-time copy of Players / Games / Stats from the old Supabase database into a new Firestore database. Runs entirely in your browser — nothing is sent anywhere except Supabase (read) and Firebase (write).

1. Source — Supabase (pre-filled from the public repo, read-only)
2. Destination — Firebase web config

Firebase Console → Project settings → General → Your apps → Web app → SDK setup and configuration. Paste the whole firebaseConfig object below (or fill the fields individually).

3. Sign in (only needed if your Firestore/Storage rules already require auth)

If you haven't published the real (locked-down) rules yet, skip this — the default temporary-open rules don't need it. If you already published the real firestore.rules / storage.rules (write requires sign-in), sign in below with a Firebase Auth account first (see AUTH_SETUP.md for how to create one), so the migration writes as an authenticated user instead of needing the rules reopened.
